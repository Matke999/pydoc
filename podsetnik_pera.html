Podsetnik za Kolokvijum (by Pera)¶

Podsetnik za pripremu kolokvijuma iz Inteligentnih sistema / Veštačke inteligencije. Svaka sekcija sadrži korake i odgovarajući kod.

0. Sređivanje podataka¶

KORACI
  • Učitavanje podataka: pd.read_csv('path', na_values=['-', ' ', '']) — direktno zamenjuje specijalne nedostajuće vrednosti (-, razmak, blanko) sa NaN
  • Zamena specijalnih vrednosti (ako nisu zadati u read_csv): data_subset.replace(['-', ' ', ''], np.nan, inplace=True)
  • Pretvaranje numeričkih kolona u numeric: pd.to_numeric(col, errors='coerce') — NE i tekstualne!
  • Tekstualne promenljive → OneHotEncoding samo kada ima smisla za model
  • Proveriti NA vrednosti: ako ima značajan broj → dropna()
  • Shapiro test: normalna raspodela (p≥0.05) → fillna(mean), nije normalna (p<0.05) → fillna(median), kategoričke → fillna(mode()[0])
KOD 
# Učitavanje sa direktnom zamenom specijalnih vrednosti

    stat, p = shapiro(series)

    data_numeric[col] = data_numeric[col].fillna(median)
data_numeric.isna().sum()

1. Multiple Linearna Regresija¶

KORACI
  1. Iscrtati korelacionu matricu (helper) — odabrati atribute sa korelacijom > 0.5 sa ciljnom promenljivom
  2. Podeliti na train (80%) i test (20%) skup
  3. Kreirati OLS model ISKLJUČIVO NA TRAIN SKUPU
  4. Tumačenje modela:
    • Reziduali: odstupanja predviđene od stvarne vrednosti
    • R²: % objašnjene varijabilnosti ciljne promenljive
    • Intercept: vrednost izlaza kada su sve nezavisne promenljive = 0
    • Koeficijenti: povećanje za 1 jedinicu → povećanje/smanjenje izlaza
    • P-values < 0.05: statistički značajna vrednost
    • F-statistika: što veća, p-vrednost što manja = bolji model
  5. Predikcije ISKLJUČIVO NA TEST SKUPU
  6. Četiri dijagnostička grafikona:
    • Residuals vs Fitted: reziduali raspoređeni oko horizontalne linije ≈ 0
    • Normal Q-Q: tačke duž dijagonale = normalna raspodela reziduala
    • Scale-Location: crvena linija horizontalna, tačke ravnomerno raspoređene
    • Residuals vs Leverage: identifikacija outliera i uticajnih tačaka
  7. Izračunati metrike (RSS, R², RMSE)
  8. Proveriti multikolinearnost: VIF > 2 → izbaciti kolonu → ponovo izračunati VIF
KOD 
lm1 = smf.ols(f'{target} ~ ' + ' + '.join(features), data=train_df).fit()
print(lm1.summary())    # R², F-statistika, p-vrednosti koeficijenata
y_pred = lm1.predict(test_df[features])
rss = ((y_pred - y_true) ** 2).sum()
tss = ((y_true.mean() - y_true) ** 2).sum()  # TSS meri totalnu „nepredvidivost"
r2_test  = 1 - rss / tss       # R² na test-skupu — veće je bolje
rmse_test = np.sqrt(rss / len(y_true))  # RMSE — tezimo nuli
print(f"RSS  = {rss:.2f}")
print(f"R²   = {r2_test:.3f}")
print(f"RMSE = {rmse_test:.2f}")
# Drugi način (sklearn):
rss       = mean_squared_error(y_true, y_pred) * len(y_true)
r2_test   = r2_score(y_true, y_pred)
rmse_test = mean_squared_error(y_true, y_pred) ** 0.5

Upozorenje

random_state=123 za regresiju (NE 42), bez skaliranja, bez stratify. Evaluacija kroz .summary(), ne sklearn metrikama.

def compute_basic_eval_measures(cm, model_name=""):
    TP = cm[1,1]; TN = cm[0,0]
    FP = cm[0,1]; FN = cm[1,0]
    accuracy  = (TP + TN) / cm.sum()
    precision = TP / (TP + FP)
    recall    = TP / (TP + FN)
    F1        = 2 * precision * recall / (precision + recall)
    return pd.Series([accuracy, precision, recall, F1],
                     index=['accuracy', 'precision', 'recall', 'F1'],
                     name=model_name)

  2. Proveriti outliere (IQR metoda):

    • Za kolone bez outlijera → MinMaxScaler
  3. Proveriti normalnu raspodelu (shapiro) — samo za odabir skalera
  4. Podeliti na train i test skup (stratify=y)
  5. GridSearchCV za optimalno K: neparne vrednosti range(3,26,2), cv=10, scoring=’accuracy’
  6. Kreirati kNN model sa optimalnim K
  7. Iscrtati i prokomentarisati matricu konfuzije
  8. Izračunati metrike
KOD 
def count_outliers(variable):
    q1 = variable.quantile(0.25)
    q3 = variable.quantile(0.75)
    iqr = q3 - q1
    lower = q1 - 1.5 * iqr
    upper = q3 + 1.5 * iqr
    return ((variable < lower) | (variable > upper)).sum()

4. Klasifikacija: Neuronske Mreže¶

KORACI
  1. Skalirati podatke (RobustScaler ili MinMaxScaler — videti prethodne modele)
  2. Podeliti na train i test skup (stratify=y)
  3. Kreirati MLPClassifier sa proizvoljnim parametrima (hidden_layer_sizes=(64,32), max_iter=1000, solver=’sgd’)
  4. Tokom treninga mreža izvršava:
    • Forward propagation: ulazni podaci → predikcija
    • Računanje greške (loss): predikcija vs stvarne vrednosti
    • Backward propagation: određivanje uticaja svakog parametra na grešku
    • Ažuriranje parametara: minimizacija greške (gradient descent)
    • Jedan prolazak kroz ceo trening skup = jedna epoha
  5. Prikazati i prokomentarisati loss_curve_
  6. Iscrtati i prokomentarisati matricu konfuzije
  7. Izračunati i objasniti evaluacione metrike

5. Hijerarhijska Klasterizacija¶

KORACI
  1. Iscrtati matricu korelacije — izbaciti visokokorelisane promenljive (OSIM prethodno enkodovanih kategoričkih!)
  2. Proveriti outliere:
    • Ako ima > 10% outlijera → izbaciti kolonu
    • Ako ima ≤ 10% → winsorize
